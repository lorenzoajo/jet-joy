# Jet Joy Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Mobile-first PWA cartoon 3D flight game with 5 missions.
**Architecture:** Framework-agnostic TS engine (`src/game`) on Three.js; Vue 3 UI (`src/ui`) reads a throttled HUD snapshot and sends commands. Pure logic (fuel, missions, rating, progress, flight math) is unit-tested with Vitest.
**Tech Stack:** Vue 3, TypeScript (strict), Vite, Three.js, vite-plugin-pwa, Vitest, devenv, Nix flakes (buildNpmPackage).
**Spec:** docs/superpowers/specs/2026-11-26-jet-joy-design.md

## Global Constraints
- No external art assets; all meshes procedural, flat/toon shading.
- No Vue reactivity in per-frame code; HUD snapshot ≤10Hz.
- iOS Safari: audio + DeviceOrientation permission requested on first tap; `viewport-fit=cover`, safe-area insets; `touch-action: none`.
- Strict TS, no `any`.
- `nix build` outputs static site in `$out`.

## Review Focus
- Fuel exactly 0 → mission fails once (no repeated failure events). Test in Task 2.
- Mission completes on the same frame fuel hits 0 → success wins. Test in Task 2.
- Corrupt/missing localStorage → progress defaults, no throw. Test in Task 3.
- Player leaving map bounds → steered back, never NaN position. Test in Task 4.
- Tab hidden/large dt → dt clamped (≤0.05s). Test in Task 4.
